Đừng hard-code thông tin môi trường vào code lâu dài.

Hiện tại để code nhanh thì:
spring.datasource.url=jdbc:mysql://localhost:3307/core_db
spring.datasource.username=root
spring.datasource.password=root

hoàn toàn được.

Nhưng sau này nên chuyển thành:
spring.datasource.url=${DB_URL}
spring.datasource.username=${DB_USERNAME}
spring.datasource.password=${DB_PASSWORD}

và dùng .env.

Ví dụ:
DB_URL=jdbc:mysql://localhost:3307/core_db
DB_USERNAME=root
DB_PASSWORD=root

Như vậy khi chuyển từ local → Docker chỉ cần đổi environment.
